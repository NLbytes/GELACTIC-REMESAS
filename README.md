# Galactic Remesas
Aplicación web desarrollada como proyecto académico para simular el proceso de solicitud y gestión de remesas de la empresa ficticia **Galactic**.
# Funcionalidades
* Ingreso de datos del emisor y beneficiario.
* Selección de moneda de destino: USD, VES y EUR.
* Conversión del monto desde CLP.
* Cálculo automático de una comisión del 0,10 %.
* Generación del valor total de la operación.
* Asignación de número de operación.
* Gestión del estado de la solicitud: pendiente, aprobada o rechazada.
* Generación de comprobante de la operación.
# Tecnologías utilizadas
* HTML5
* CSS3
* JavaScript
* Visual Studio Code

> Proyecto desarrollado con fines académicos para aplicar fundamentos de programación, estructuras de control y automatización de procesos mediante una aplicación web.
